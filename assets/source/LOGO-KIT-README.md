# MacBite — Logo Vector Rebuild

Rebuilt from the supplied JPEG as true vector artwork. All lettering is
converted to outlines, so nothing depends on a font being installed.
Every SVG has a transparent background.

## Colours

| Role            | Hex       |
|-----------------|-----------|
| Brand Red       | `#E32119` |
| Brand Gold      | `#F7A81B` |
| Deep Red (keyline / backgrounds) | `#7E1113` |
| Field Red (backgrounds)          | `#9E1B1B` |
| White           | `#FFFFFF` |

## Files

**Primary (full colour)**
- `macbite-logo-stacked.svg` — main lockup, white tagline. Use on red/dark/photo.
- `macbite-logo-stacked-onlight.svg` — same, dark tagline. Use on white/light.
- `macbite-logo-horizontal.svg` — wide lockup for site headers, letterheads, email signatures.
- `macbite-mark.svg` — cloche only. Social avatars, favicons, packaging, stamps.
- `macbite-appicon.svg` — mark on a rounded red tile. App/PWA icon.

**Single colour** (for embroidery, receipts, stamps, one-colour print, dark UI)
- `macbite-logo-stacked-white.svg` / `macbite-mark-white.svg`
- `macbite-logo-stacked-black.svg` / `macbite-mark-black.svg`
- `macbite-logo-stacked-red.svg`

**PNG** — `png/` holds pre-rendered transparent PNGs at 180/512/1024/2048px.

## Usage notes

- Minimum width for the full stacked lockup: ~120px. Below that use `macbite-mark`.
- Keep clear space around the logo equal to the height of the cloche knob.
- Never re-colour, stretch, add shadows, or place the white-tagline version on a light background.

## Typeface

The wordmark is set in **Titan One** and the tagline in **Caveat**, both
SIL Open Font License — free for commercial use, including outlined in a logo.
These are close matches to the original, not the exact source font. If the
original font file exists somewhere, send it and the wordmark can be reset exactly.
